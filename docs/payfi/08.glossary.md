# Glossary

| Term | Meaning |
|---|---|
| Advance | The first transaction of a payout: mint POT, post it, borrow 90% of the face, pull the PO's 10% from custody |
| Basket (cover) | Assets the PO locks in the settlement account as on-chain cover: XLM and a test USDC on testnet. The borrowed stablecoin is never in it |
| Custody account | The PO's Stellar account holding the first-loss deposit and working balance, signed by the PO's custody keys and the trustee |
| Custody gate | A contract with a fixed address list through which custody money reaches the settlement account, within an allowance custody sets |
| Execution contract | A contract that runs a list of calls as one transaction. The gated one carries the PO's flows and stores take-overs; the gate-free one carries liquidations |
| First-loss deposit | PO money locked in custody, meant to absorb a loss before the LPs do |
| Line | One PO's set-up: market, POT, custody, settlement account, rules and the service's records. The testnet lines are `beta`, `beta-2` and `sim` |
| Liquidation | A repayment of part of the debt by anyone, in exchange for basket assets, allowed while the cover is below 15% of the debt |
| LP | Liquidity provider: deposits stablecoin into a PO's lending market and earns its interest |
| PO | Payment orchestrator: the borrower, which pays receivers today and repays when the sender's fiat clears |
| POT | Payment Obligation Token: one per dollar of a pay-in's face, minted in the advance and burned at repayment |
| POT Mint Account | The Prime smart account that alone can mint POT, and only inside an advance |
| Release | The second transaction of a payout: the settlement account pays the receiver in full |
| Settlement account | The PO's Prime smart account on Stellar, the market's borrower, bound by its rules |
| Signing service | Untangled's service that screens receivers, checks limits, co-signs and keeps each line's records |
| Step | An authorisation or transaction the service builds for one key to sign, checked by the SDK first |
| Take-over | Untangled's recovery path after a default: queued, a fixed wait, then run, with the price and debt checked at the run |
| TUSD | The test dollar that stands in for a real stablecoin on testnet |
