# Account Permissioning: OZ Policy Builder

The OZ Policy Builder is an off-chain TypeScript toolkit that produces a policy installable on an OpenZeppelin Stellar smart account. Given a recorded Soroban transaction, it derives the narrowest set of OZ primitive policies that permit exactly the observed behaviour — nothing more.

## The record → synthesise → install pipeline

```
1. Record          2. Synthesise         3. Install
   ─────────          ──────────            ────────
   Capture tx         Analyse trace          Submit to
   from network       Infer minimal scope    OZ smart
   or simulation      Flag Path-B gaps       account
```

### Step 1 — Record

The recorder captures a Soroban transaction and produces a normalised `RecordedTransaction`. This can come from:

- **Live network** — the recorder observes real on-chain events and XDR.
- **Simulation** — `simulateTransaction` returns a result without signing. Note: simulation mode has no raw events, so the recorder cannot perform its events cross-check and reduces `parseConfidence`. It fails closed at the default gate; callers must explicitly provide a `confidenceOverride`.

The recorder produces a `parseConfidence` score: `1 - (unknownContracts + opaqueScVals) / total`. A recording with any unknown contract or opaque ScVal does not synthesize.

### Step 2 — Synthesise

Two synthesis front-ends feed one composition core:

| Front-end | Input | Deterministic? |
|---|---|---|
| **Mandate** | Declarative spec (contract, method, spending limit, window, approvals) | Yes — pure mapping to policy IR |
| **Recording** | `RecordedTransaction` from step 1 | Yes — same input always produces byte-identical output |

Both lower to a **PolicyIR** (policy intermediate representation), then the OZ Accounts adapter (`CustodyAdapter`) compiles it.

**What the adapter produces (Path A — OZ built-in primitives):**

| IR construct | OZ output |
|---|---|
| `scope.contract` | `ContextRuleType::call_contract(contract)` |
| `window_spent(token, w) ≤ limit` | `spending_limit` primitive |
| `approval.threshold` | `simple_threshold` / `weighted_threshold` primitive |
| `expiry.validUntilLedger` | `ContextRuleDraft.validUntilLedger` |

**What is NOT covered (Path B):** per-method scoping, arg allowlists (recipient), oracle price bounds, invocation-count windows, nested boolean / negation. These are surfaced as `uncovered[]` warnings — the policy is never silently weakened.

The synthesizer is fail-closed everywhere: no bound is invented, no ambiguity is resolved by assumption.

### Step 3 — Install

The output is a `ProposedPolicy` carrying the `ContextRuleDraft` and OZ policy primitive references. Installing it on an OZ smart account calls `add_context_rule` with the compiled context rule and a map of `PolicyRef` → policy instance addresses.

Install, on-chain verify, simulate, and the Rust interpreter are **later phases**.

## Packages

| Package | Description |
|---|---|
| `@crediolabs/policy-synth` | TypeScript synthesis core (`packages/policy-synth`) |
| `@crediolabs/policy-builder-mcp` | MCP server for AI agent tool-use integration (`apps/policy-builder-mcp`) |
| `apps/policy-builder-cli` | CLI for scripted policy authoring |
| `apps/policy-builder-web` | Browser UI for the install flow (testnet, Freighter or local keypair) |

## Deployed contract instances

See [`DEPLOYMENTS.md`](https://github.com/untangledfinance/octogate/blob/main/DEPLOYMENTS.md) in the octogate repo for the full registry, including:

- Policy interpreter (Rust, on-chain predicate enforcement) — testnet and mainnet addresses
- OZ built-in policy primitives (`spending_limit`, `simple_threshold`, `weighted_threshold`) — Stellar testnet and mainnet instances
- Reflector Pulse oracle feeds (primary + secondary) pinned into the interpreter

> **Note:** The mainnet interpreter deployment (2026-08-04) is **unaudited**. The `get_interpreter_info` tool still refuses `network: 'mainnet'`. A mainnet install currently requires `allowUnpinnedInterpreter: true` and `allowUnpinnedRpcUrl: true`. Do not point end users at this instance until the package-side pin lands.
