# Curation Wallet Solutions

OctoVault supports **two multisig solutions**: **LOBSTR Vault** and **Fireblocks MPC**.  
These ensure vault assets are secured among the signers within the curator’s governance structure.  
⚠️ **Note:** Untangled never custody assets.  

The following multisigs are supported on both the **LP App** and the **Curator App**.

## LOBSTR Vault

- Works with wallets such as **LOBSTR** and **Freighter**  
- Uses the **multisignature technology** of the Stellar Network  
- Allows you to create a local signer account and verify transactions from multiple Stellar accounts  

Features:

- Protect several accounts from a single device  
- Protect a single account across multiple devices  
- Require additional approval from a separate device  
- Example: require **3 approvals out of 5 devices**  

👉 Learn more: [LOBSTR Vault](https://vault.lobstr.co/)

## Fireblocks MPC (Multi-Party Computation) Wallet

- Enabled via **WalletConnect**  
- Uses **MPC technology** where a private key is split into multiple shares across different parties  
- No single party ever has full access to the complete private key  

### Key Features

- **Threshold Signing (n/m):**  
  Require *n* out of *m* key shares to sign a transaction (e.g., **2-of-3**)  
- **Off-Chain Governance:**  
  - Key management handled off-chain through cryptographic protocols  
  - Governance actions (e.g., changing signers, thresholds) are managed through the MPC protocol, not blockchain transactions
