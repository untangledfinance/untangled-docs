# Install rules for an agent

The video was recorded with an earlier version of the rule dialog. The steps
below match the current app; the three rules are the same.

The walkthrough sets up three swap rules on the Aquarius XLM/USDC pool, each
spending custody's XLM and returning USDC to custody:

| Amount per swap | Who approves | Wait |
|---|---|---|
| Up to 10 XLM | Agent | None |
| More than 10, up to 100 XLM | Agent | 12 ledgers (about a minute) |
| More than 100 XLM | Agent and Admin | None |

Each row is its own rule. To add one:

1. As a signer of the Prime Account, go to **Policies**. Under **Start from a
   template**, select **Swap on Aquarius, proceeds to custody**. The template
   works through the account's execution contract and custody gate. If none is
   connected in this browser, the app says so and opens **Manage execution**.
2. Pick the pool from the list, or paste its address. The app accepts it only if
   it is an Aquarius pool.
3. Under **Token in**, pick the token custody spends (XLM here). The pool's other
   token is the token out (USDC).
4. Enter **Max per swap** in whole tokens. That amount itself is allowed. Then
   select **Preview**.
5. **Add a rule** opens with your wallet as the first signer. Add the agent, and
   for the top band the Admin. Set **Approvals required**: 1 lets each listed
   signer act alone, 2 makes the agent and the Admin both sign. Check the **Rule
   name**.
6. The policy, shown as a tree, holds three values with defaults: the minimum
   amount per swap (0), the least the swap must return to custody (1 base unit
   of the token out) and the wait (0 ledgers). Change them there before you
   install:
   - Bands don't overlap if each starts one base unit above the last one's
     maximum. XLM has 7 decimal places, so "more than 10 XLM" is a minimum of
     100000001.
   - Set a real minimum return. At 1 base unit, the rule gives the swap no
     price protection.
   - Set the wait in ledgers, about 5 seconds each. Every move also waits at
     least the gate's own minimum.
7. Select **Install rule** and sign.

Installing a rule needs the account's approval count, so another signer may
have to co-sign it from the Queue.

When all three are installed, **Policies** lists them, and you can open one to
see its details.

The other templates that move custody's funds work the same way, such as
**Allocate to Blend** and **Withdraw from Blend to custody**; see
[Policies](../04.reference/02.policies.md).
