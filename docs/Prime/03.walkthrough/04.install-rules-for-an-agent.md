# Install rules for an agent

<video controls width="100%" preload="none" poster="/img/prime/video-04-install-rules-for-an-agent.jpg" src="/video/prime/04-install-rules-for-an-agent.mp4">
  Your browser does not support the video tag.
</video>

The video sets up three swap rules on the Aquarius XLM/USDC pool:

| Amount per swap | Who approves | Wait |
|---|---|---|
| Under 10 XLM | Agent | None |
| 10 to 100 XLM | Agent | 12 ledgers (about a minute) |
| 100 XLM and up | Agent and Admin | None |

To add a rule:

1. As a signer of the Prime Account, go to **Policies** and select
   **Custody-funded action**.
2. Choose what the agent may do: **Swap on Aquarius**, **Supply to Blend** or
   **Withdraw from Blend**. The dialog fills in the account's custody gate. If
   the gate was set up in another browser, paste its address.
3. On mainnet, pick the pool from the list (search by token or address). On
   testnet, as in the video, paste the pool's address. For a swap, pick the
   direction (here, spend XLM and receive USDC).
4. Enter the amount band. It runs from the first amount up to but not including
   the second, so bands of 0 to 10 and 10 to 100 don't overlap.
5. Optionally set a minimum wait in ledgers. If you leave it empty, the gate's
   wait applies.
6. For a swap, enter the least the swap must return to custody, in the asset
   received.
7. Add the wallets that may act in this band and how many of them must approve
   each move.
8. Select **Install this permission** and sign.

![The rule dialog, top half](/img/prime/rule-dialog.webp)

![The rule dialog, bottom half](/img/prime/rule-dialog-wait.webp)

Installing a rule needs the account's approval count, so another signer
co-signs it from the Queue. The co-sign page lists the venue, the band and who
may act.

Each band is a separate rule. When all three are installed, **Policies** lists
them, and you can open one to see its details.

![Policies with the three swap rules](/img/prime/policies-tab.webp)

For other rule types, such as spending limits, see
