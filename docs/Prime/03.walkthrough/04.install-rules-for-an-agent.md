# Install rules for an agent

<video controls width="100%" preload="none" poster="/img/prime/video-04-install-rules-for-an-agent.jpg" src="/video/prime/04-install-rules-for-an-agent.mp4">
  Your browser does not support the video tag.
</video>

A rule decides who may move custody's money, on which venue, how much at a time,
with how many approvals, and how long the move must wait. The account checks it
on chain, where anyone can read it.

In the video, Signer A gives the Agent three swap rules on the Aquarius XLM/USDC
pool, sized by amount:

| Rule | Amount per swap | Who may act | Minimum wait |
|---|---|---|---|
| Small | Under 10 XLM | The Agent alone | None, so it runs at once |
| Medium | 10 to under 100 XLM | The Agent alone | 12 ledgers, about a minute |
| Large | 100 XLM and up | The Agent and the Admin, both approving | None |

## Open the rule dialog

A signer of the Prime Account opens **Policies** and selects **Custody-funded
action**. The dialog, **Let an agent move custody's money**, finds the account's
custody gate. If the gate was set up in another browser, paste its address under
**Gate address, if it is not the one above**.

![Let an agent move custody's money: the move, the gate and the pool](/img/prime/rule-dialog.webp)

## Fill it in

| Field | What to enter |
|---|---|
| What it may do | **Swap on Aquarius**, **Supply to Blend** or **Withdraw from Blend** |
| Pool | The pool's address. For a swap, choose the direction too, such as spend XLM and receive USDC. |
| Amount band | From the first amount up to, but not including, the second, for every single move. Where two bands meet at the same number, the higher band owns it. |
| Minimum wait | The least number of ledgers a move under this rule waits before it can run. Leave it empty to use only the execution contract's own minimum, which is the wait set in the gate. |
| Least this swap must return to custody | For a swap, the floor in the asset received. It is fixed when the rule is written. |
| Who may act | The wallets or agent keys allowed to act in this band |
| Approvals required | How many of them must approve each move, such as 1 of 1 for the Agent alone, or 2 of 2 for the Agent and the Admin |

![The rest of the dialog: minimum wait, return floor, who may act and approvals](/img/prime/rule-dialog-wait.webp)

Select **Install this permission** and approve in your wallet. Each band is its
own rule, so you can add a band today and another later.

## Co-sign the install

Installing a rule changes the account, so it needs the account's approval count.
Another signer opens the request's co-sign link from the Queue. The co-sign page
spells out the rule: the venue, the amount band and who may act. They select
**Sign and continue**, and the rule is on chain once they approve.

Repeat for each band. **Policies** then lists every rule, and selecting one shows
what it permits.

![Policies listing the three swap rules](/img/prime/policies-tab.webp)

Other kinds of rule, such as a spending limit or a Blend supply, are described
in [Policies](../04.reference/02.policies.md).
