# Create the execution contract

<video controls width="100%" preload="none" poster="/img/prime/video-03-create-the-execution-contract.jpg" src="/video/prime/03-create-the-execution-contract.mp4">
  Your browser does not support the video tag.
</video>

The execution contract runs a whole batch of calls as one transaction, through
the custody gate. Each Prime Account has its own, and the gate set-up already
worked out its address. The Prime Account's signers create it.

In the video, Signer A creates it and Signer B co-signs from a link.

## Create it

1. A signer of the Prime Account opens **Accounts**, expands the Prime Account
   and selects **Manage execution**.
2. The dialog shows the account, its execution adapter marked **not created
   yet**, and the custody gate connected beneath it. It also says how many
   approvals the account needs.
3. Select **Create execution contract** and approve in your wallet.

![Manage execution before the contract exists](/img/prime/manage-execution-create.webp)

## Collect the other approvals

Creating the contract changes the account, so it needs the account's approval
count, two of three in the video. When your signature is not enough, the app
shows **More signatures needed**: who has signed, who can still sign, and a
co-sign link that expires in about 24 hours. The request is also saved in the
Queue, so you can close the dialog.

![More signatures needed, with the co-sign link](/img/prime/more-signatures-needed.webp)

Another signer connects, opens **Transactions**, then **Queue**, and copies the
request's co-sign link. The co-sign page reads the transaction itself and shows
exactly what will be signed: the function, the account it acts as, the rule, and
every approver's full address. They check it, select **Sign and continue** and
approve in their wallet. Once the count is met, the transaction is sent.

![The co-sign page, showing what will be signed](/img/prime/cosign-review.webp)

## Let stored moves run

With a time lock, a move is stored first and runs later. The execution contract
can run a stored move only if the account has a rule that lets it. Back in
**Manage execution**, select **Let stored moves run** and approve. The other
signers co-sign it from the Queue the same way.

**Manage execution** then shows the execution adapter as active, the custody gate
beneath it, the gate's wait and run window, and which rule stored moves run
under.

![Manage execution with the contract live](/img/prime/manage-execution.webp)
