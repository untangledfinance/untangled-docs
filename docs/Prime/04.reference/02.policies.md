# Policies

A policy is a condition the account checks before it authorises a call. If the
call doesn't meet it, the transaction fails. Use policies to limit what an agent
key can do.

The **Policies** page lists the account's rules. Some templates install several
rules that work together; the list shows them as one row that you can expand.
**View** opens a rule's details. The templates are below the list.

## Templates

| Template | Allows |
|---|---|
| Custody-funded action | Supplying, withdrawing or swapping with custody's funds through the custody gate, within an amount band. Swap proceeds and withdrawals go back to custody. Used in the [walkthrough](../03.walkthrough/04.install-rules-for-an-agent.md). |
| Aqua swap | Swaps on one Aquarius pool in one direction, with a cap per swap |
| Spending limit | Transfers of one asset, with a cap over a number of ledgers |
| Blend supply | Supplying from your wallet to a Blend pool, with the position held by the Prime Account |
| Blend withdraw | Withdrawing one Blend reserve to your wallet |
| Blend claim to wallet | Claiming a Blend pool's emissions to a wallet |
| Pull funds | Pulling an asset from the connected wallet into the account, with a cap per pull and one allowed destination |

Each template asks for the signer it applies to, the contract addresses, the
caps, and a name for the rule. If none fits, use **Add a custom policy**.

The Aqua swap template can route swaps through the execution contract so its cap
is enforced. Prime Execution doesn't run those routed swaps, so only choose that
option for an agent that submits its own transactions.

## What a policy can restrict

- the contract it may call
- the method
- the amount per call
- the recipients
- the total spent over a period (with a spending limit)
- the minimum a trade must return

Rules that expire after a set time can be set on chain but not in the app. For
how to set spending limits, see
[Setting up policies](../05.security.md#setting-up-policies).

## Installing and revoking

Fill in a template, check the summary and sign. If the account needs more
approvals, the other signers co-sign it from the Queue. If the install button is
greyed out, the reason is shown next to it.

To revoke, open the rule and remove the policy, then sign. This also resets the
policy's counters, such as a spending limit's running total.

If a row holds several rules, removing one of them stops the others working
too, and they stay listed until you remove them. The confirm dialog warns you
when this applies.

## Before giving a key to an agent

Read [Setting up policies](../05.security.md#setting-up-policies).

The [OctoGate user guide](../../OctoGate/account-permissioning/user-guide.md) has
recordings of a daily claim limit, a monthly subscription cap and a swap minimum,
each passing and then failing on testnet.
