# Troubleshooting

The messages below are the words on screen. Each row gives the fix in one line.

## Reads and balances

| Message | Where | Fix |
|---|---|---|
| Couldn't read the position | Repay and withdraw | Reload the page. Check that your wallet is on Base Sepolia. |
| Couldn't read the chains | A repay or withdraw run | Reload the page. The run picks up from the chains. |
| Couldn't read Solana | A Kamino Open or Close | Select **Retry**. |
| Could not read Solana. | Setup dialog and rules | Try again. The setup and rules read again when you return to them. |
| Balances not read | Close shortfall panel | Select **Retry**, or **Read again**. |
| Retrying | Repay and withdraw form | Wait. The form needs the reserve reading before it can check the amounts. |
| Not a number | Repay or Withdraw field | Type digits and a decimal point only. |

## Repay and withdraw

| Message | Fix |
|---|---|
| Above what is owed | Select **MAX** or type less than the owed amount. |
| Above 6 USDC | Repay at most 6 USDC in one run, then run again for the rest. |
| Kamino holds X, or OctoLend holds X | Repay no more than the amount the yield source holds. |
| Below 1 USDC | Repay at least 1 USDC, or leave the Repay field empty to withdraw only. |
| Above your collateral | Withdraw no more than the tXAU in the position. |
| Above the safe maximum | Withdraw no more than the **Max** shown under the field. |
| Above the daily allowance X | Wait for the allowance to refill, or withdraw up to X. |
| Nothing owed | The debt is zero. There is nothing to repay. |
| Nothing in Kamino, or Nothing in OctoLend | The yield source holds too little to cover the Circle fee, so nothing can be repaid from it. [NEEDS SOURCE: the right action for this case.] |
| Close reserve 1 first | [NEEDS SOURCE: the meaning of this message and its fix.] |
| Add X USDC to custody first | Select **Add**. Your wallet sends X USDC to custody. |

## Open and Close

| Message | Fix |
|---|---|
| Health factor low: X | Borrow less. The warning shows below 1.6. |
| The health factor would fall to X, below the stop at 1.25. | Borrow less. Open stops below 1.25. |
| Budget used, refills [date] | Wait for the refill date. |
| Market closed | Wait. The market reopens on its own. [NEEDS SOURCE: the market hours.] |
| Key SOL low | Send SOL to the address on the card, using the copy button. Then select **Retry**. |
| Key not on this browser | Open the page in the browser where the key was made, or add this browser as a signer on the **Keys** list. [NEEDS SOURCE: the exact button label.] |
| Fee above limit | On a Close, wait and try again. The fee changes with Circle's quote. |
| Waiting for the second signer | Ask the other custody signers to approve the request in the **Queue**. |
| Waiting for co-sign | Ask the other custody signers to approve the request in the **Queue**. |
| Couldn't read the queue | Select **Retry**. The page does not propose anything until the queue can be read. |
| Repay & withdraw needs its own rule on this account: one custody signature, once. | Not an error. Select **Set up** once. |
| The Repay & withdraw rule is not the one this app writes: [reason] | [NEEDS SOURCE: the fix for a rule this app did not write.] |

## Signer B

| Message | Fix |
|---|---|
| Needs ETH | Send ETH to signer B's address, or wait for the relayer's top-up. The top-up shows as **Funding**. |
| Funding | Wait. The top-up is in progress. |
| On in another browser | Use the browser that holds signer B, or revoke it there. |
| This browser already holds a signer for this custody. | Select **Forget** first. Then make a new one. |

## Fees and sponsor

| Message | Fix |
|---|---|
| Sponsor is off. This key pays. | Keep enough SOL or XLM in the key. |
| Sponsor limit reached. This key pays. | Keep enough SOL or XLM in the key. The limit resets on the service's schedule. |
| Sponsor refused. This key pays. | Select **Retry**. |
| Sponsor could not check it. This key pays. | Select **Retry**. |
| Sponsor unreachable. This key pays. | Wait, then select **Retry**. |

See [Fees and gas sponsorship](./08.fees-and-gas.md).
