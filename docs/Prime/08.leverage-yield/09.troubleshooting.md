# Troubleshooting

The messages below are the words on screen. Each row gives the fix in one line.

## Reads and balances

| Message | Where | Fix |
|---|---|---|
| Couldn't read the position | Repay & withdraw | Reload the page. Check that your wallet is on Base Sepolia. |
| Couldn't read the chains | A repay or withdraw run | Reload the page. The run picks up from the chains. |
| Couldn't read Solana | A Kamino Open or Close, or the Rules tab | Select **Retry**. |
| Could not read Solana. | Setup dialog and rules | Try again. |
| Balances not read | Close shortfall panel | Select **Retry**, or **Read again**. |
| Retrying | Repay & withdraw form | Wait. The form needs the reserve reading before it can check the amounts. |
| Could not read one of your other Safes | **Queue**, above **Waiting for other signers** | Select **Retry**. |
| Not a number | Repay or Withdraw field | Type digits and a decimal point only. |

## Repay & withdraw

| Message | Fix |
|---|---|
| Above what is owed | Select **MAX**, or type less than the owed amount. |
| Above 6 USDC | Repay at most 6 USDC in one run, then run again for the rest. |
| Kamino holds X, or OctoLend holds X | Repay no more than the amount that yield source holds. |
| Nothing in Kamino, or Nothing in OctoLend | The Repay field is off, because the yield source cannot cover the Circle fee. Withdraw still works on its own. |
| Below 1 USDC | Repay at least 1 USDC, or leave Repay empty to withdraw only. |
| Above your collateral | Withdraw no more than the tXAU in the position. |
| Above the daily allowance X | Withdraw up to X now, or wait for the 24-hour allowance to refill. |
| Above the safe maximum | Withdraw no more than the **Max** shown under the field. |
| Nothing owed | The debt on Base is zero, so there is nothing to repay. |
| Close reserve 1 first | A partial run waits until the reserve 1 (Morpho) debt is zero. The app reads that debt and has no step that repays it. [NEEDS SOURCE: the action that clears the reserve 1 debt.] |
| Add X USDC to custody first | Select **Add**. Your wallet sends X USDC to custody. |
| Repay & withdraw needs its own rule on this account: one custody signature, once. | Not an error. Select **Set up** once. |
| Waiting for the second signer | Ask the other custody signers to approve the request in the **Queue**. |
| The Repay & withdraw rule is not the one this app writes: reason | The reason names the part that differs, for example the members, the scopes, or the tXAU allowance: it must be 0.1 tXAU a day and spent by this rule only. No button appears. [NEEDS SOURCE: the fix for each reason.] |

## Open and Close

| Message | Fix |
|---|---|
| Health factor low: X | Borrow less. The warning shows below 1.6. |
| The health factor would fall to X, below the stop at 1.25. | Borrow less. Open stops below 1.25. |
| Budget used, refills [date] | Wait for the refill date. |
| Market closed | The form is off while the market is closed. Check again later. |
| Key SOL low | Send SOL to the address on the card, using the copy button. Then try the step again. |
| Key not on this browser | This browser holds no key for this account. On the **Rules** tab, the keeper card shows **Not installed** with a **Set up** button, which leads to the Rules tab, where the browser key is made and added. Or open the page in the browser that holds the key. |
| Fee above limit | On a Close, wait and try again. The fee changes with Circle's quote. |
| Waiting for co-sign | Ask the other custody signers to approve the request in the **Queue**. |
| Waiting for other signers | Ask the other custody signers to approve the request in the **Queue**. |
| Couldn't read the queue | Select **Retry**. The page does not propose anything until the queue can be read. |
| Couldn't read the co-sign queue | Select **Retry**. The page does not propose anything until the queue can be read. |
| Taking longer than usual | Circle's attestation is slower than usual. Wait. The row links to Circle's status for the burn. |
| Forward failed | Select **Deliver** on the **Mint on Base** row. See [Close](./05.close.md#deliver). |
| The burn did not go through. Nothing was burned. | Start the Open again. |
| Could not confirm | The deposit row on the Open run shows this when the Solana receipt change does not match the send. The row has no button. **Retry** appears only when a read fails. [NEEDS SOURCE: the step to take when the row stays at Could not confirm.] |
| Not a custody signer | Connect a wallet that is a signer of the custody. |
| Not an owner of this account | Connect a wallet that owns the Prime Account. |
| Rule not installed | Set up the line from the **Rules** tab. |
| The keeper rules have ended, so the keeper cannot deposit or close. Renew them on the Rules tab. | Open the **Rules** tab, select the **Keeper rules** card, then **Renew**. **Renew** appears only in a browser that holds the keeper key. |
| Update the rule | Open the **Rules** tab and update the Kamino rule from its card. |

## Signer B

| Message | Fix |
|---|---|
| On in another browser | Use that browser, or select **Use this browser** to move signer B here. |
| This browser already holds a signer for this custody. | Select **Forget key** first, then make a new signer B. |
| Not allowed | Signer B refused the repay, and the card shows the reason. Select **Repay and withdraw** in your wallet, or check the **Rules** tab. |
| Signer not on this browser | Set up signer B in this browser, or select **Repay and withdraw** in your wallet. |
| Signer did not answer | Select **Repay and withdraw** in your wallet. |

## Fees and sponsor

| Message | Fix |
|---|---|
| Sponsor is off. This key pays. | Keep enough SOL or XLM in the key for the step. |
| Sponsor limit reached. This key pays. | Keep enough SOL or XLM in the key. The limit is set by the service. |
| Sponsor refused. This key pays. | Keep enough SOL or XLM in the key. The page tries the sponsor again later. |
| Sponsor could not check it. This key pays. | Keep enough SOL or XLM in the key. |
| Sponsor unreachable. This key pays. | Keep enough SOL or XLM in the key. The page tries the sponsor again later. |

See [Fees and gas sponsorship](./08.fees-and-gas.md).

## History and snapshot charts

| Message | Fix |
|---|---|
| Couldn't read your history | Reload the page. |
| Setting up… | Wait. The charts appear when the service finishes. |
| Setup failed | Select **Retry**. |
| Position: Not available now, or Kamino or Aave: Not available now | The service cannot install this item for this account. The other charts still appear. |
| too many enables from this address today | The limit is 30 Enables a day for each address, counted by UTC day, so it starts again at 00:00 UTC. The server also sends Retry-After of one hour. |
