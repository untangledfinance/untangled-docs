# Repay and withdraw

Repay and withdraw reduces an open position. It repays part of the USDC debt, with USDC brought back from the yield source, and withdraws part of the tXAU collateral to custody. Either amount can be zero. A withdraw with nothing to repay makes no bridge transfer.

To close the whole position, use [Close](./05.close.md). If the two amounts cover everything, the button becomes **Close** and runs the same Close.

:::note
Repay and withdraw needs its own rule on the account, the **repay role**. See [Rules and signer B](./06.rules-and-signer-b.md#the-repay-role). If the card asks for it, select **Set up**.
:::

## The fields

The **My position** card has a **Repay & withdraw** tab and a **Close** tab. The tab shows two fields.

| Field | Unit | Hint | Buttons |
|---|---|---|---|
| **Repay** | USDC | `Owed (all lines) X`, the debt the custody owes on Base | 25%, 50%, 75%, MAX of the repay maximum |
| **Withdraw** | tXAU | `Max X`, the most tXAU the health factor allows for the repay you typed | 25%, 50%, 75%, MAX of the withdraw maximum |

The debt is shared by both lines. The **Owed** figure is the same on the Kamino and OctoLend cards.

Under the fields, the preview line shows the health factor before and after, for example `Health factor 13.68 → 24.63`. The preview uses the smallest repay the run can make, so the health factor after the run is at least the figure shown.

## Limits

| Check | Message on the field | What it means |
|---|---|---|
| Repay above the debt | Above what is owed | Repay can be at most the debt. MAX fills it. |
| Repay above one run | Above 6 USDC | One run repays at most 6 USDC. Make a second run for the rest. |
| Repay above the yield source | Kamino holds X, or OctoLend holds X | The yield source holds less USDC than the repay needs |
| Repay below the minimum | Below 1 USDC | A run that repays must repay at least 1 USDC. Use 0 to withdraw only. |
| Withdraw above the collateral | Above your collateral | Withdraw cannot exceed the tXAU in the position |
| Withdraw above the daily allowance | Above the daily allowance X | See below |
| Withdraw below the safe level | Above the safe maximum | The health factor after the run would be below 1.5 |

**Health factor floor:** a run is refused when the health factor after it would be below 1.5. The **Withdraw** maximum is the largest amount that keeps the health factor at 1.5.

**Daily allowance:** each line can withdraw up to 0.1 tXAU in each 24-hour period. The Kamino and OctoLend lines have separate allowances. The message shows what is left. [NEEDS SOURCE: the final value of the daily allowance and the health factor floor. The figures here are this build's settings.]

**Dust:** if a withdraw would leave less than 0.000001 tXAU in the position with no debt left, it takes that small amount too.

**Close reserve:** the run must leave custody holding the Circle USDC the Close reserve needs. If it does not, the form shows **Add X USDC to custody first** with an **Add** button. See [Open a position](./03.open-a-position.md#check-the-review).

## The button

The button label follows the amounts you typed.

| Repay | Withdraw | Button | What runs |
|---|---|---|---|
| Typed | Typed | **Repay and withdraw** | The run |
| Typed | Empty | **Repay** | The run, repay only |
| Empty | Typed | **Withdraw** | One transaction on Base, no bridge |
| Owed in full | All collateral | **Close** | The existing Close, unchanged |

Select the button to check the amounts again. The app reads the chain and opens the review.

## The review

| Row | Meaning |
|---|---|
| Repay | The USDC repaid, from the yield source. On Kamino the row reads a range, for example `1.0000 to 1.0020 USDC`: the lower figure is what you typed, and the upper adds the most Circle's fee can take. The fee decides where in the range the final amount falls. |
| Withdraw | The tXAU that returns to custody, or **none** |
| Health factor after | The health factor once the run is done. Read again at this point. |
| Fee | The most Circle's fee can take, **up to X USDC**, on Kamino. The fee is zero on OctoLend. |
| From | **Kamino** or **OctoLend** |

Select **Sign** to start the run. The review shows the figures read at the press.

## The steps

| Line | Rows |
|---|---|
| Kamino, standing close rule | Withdraw from Kamino · Send to Base · Attestation · Mint on Base · Repay and withdraw |
| Kamino, one signature | Withdraw and send to Base · Attestation · Mint on Base · Repay and withdraw |
| OctoLend | Withdraw from OctoLend · Send to Base · Attestation · Mint on Base · Repay and withdraw |
| Withdraw only | Withdraw tXAU from the position to custody |

The last row finishes the run. If the step to mint or repay does not go through by itself, the card shows **Deliver** or **Repay and withdraw**. See [Close](./05.close.md#deliver) for when each appears.

## Set up the repay role

The first time, the card shows **Set up** and the line **Repay & withdraw needs its own rule on this account: one custody signature, once.** Select **Set up**, then approve the change in custody's queue.

After the first signature, if custody has two or more signers, the line **Waiting for the second signer** appears. The request waits in the **Queue** until the other signers approve it. Then the card shows the form.
