# Fees and gas sponsorship

Leverage Yield moves value across three chains, so each step has a fee. This page lists who pays each one.

## Who pays

| Cost | Paid by | Notes |
|---|---|---|
| Base transactions from your wallet: setup, Open, custody approvals, Deliver, Repay and withdraw | Your wallet, in ETH | Not sponsored. |
| Solana Open and Close transactions: mint, deposit, withdraw and burn | The fee sponsor, when it is on | The sponsor pays the network fee and the rent for the message. |
| Solana setup, Swig funding and the one-signature Close | The browser key, in SOL | Not sponsored. |
| Stellar keeper transactions: deposit, withdraw, approve and burn | The fee sponsor, when it is on | The sponsor wraps the transaction in a fee bump. The keeper key signs the transaction as before. |
| Stellar account creation and deploy | The keeper key, in XLM | Not sponsored. |
| Signer B's ETH on Base | The fee sponsor, as a top-up | Sent when signer B falls below its floor. |
| Circle's fee on Kamino | Taken from the USDC sent | See below. |

The sponsor checks each transaction before it signs the fee part. A transaction that fails the check is not sponsored.

## Circle's fee

Circle charges for the USDC that crosses from Base to the yield source. The fee depends on the transfer speed.

| Line | Speed | Fee |
|---|---|---|
| Kamino | Fast, when Circle's fee fits the limit | Up to 0.002 USDC |
| Kamino | Standard, when Fast's fee is above the limit | None. The transfer is slower. |
| OctoLend | Standard | None |

When you press the button, the app asks Circle for the fee on that amount. It uses Fast when the fee fits the 0.002 USDC limit, and Standard otherwise. The review shows the fee before you sign. On a Close, if neither speed fits, the Close is refused with **Fee above limit**.

## The sponsor's messages

When the sponsor does not pay, the page says so in one line and the browser key pays instead. The line appears under the step that was sent.

| Message | What it means | What to do |
|---|---|---|
| Sponsor is off. This key pays. | The sponsor is not running for this app. | Keep enough SOL or XLM in the browser key or keeper key for the steps. |
| Sponsor limit reached. This key pays. | The sponsor's limit for this key has been used. | Keep enough SOL or XLM in the key. The limit resets on the schedule the service sets. |
| Sponsor refused. This key pays. | The sponsor refused the transaction after its checks. | Select **Retry**. If it repeats, the key pays for each step. |
| Sponsor could not check it. This key pays. | The sponsor could not read the transaction it was given. | Select **Retry**. |
| Sponsor unreachable. This key pays. | The page could not reach the sponsor. | Wait and select **Retry**. |

"This key pays" means the browser key or keeper key covers the fee from its own balance. If the key is short, the page says **Key SOL low** with the key's address and a copy button. Send SOL to that address and select **Retry**.

## One-time costs

| Cost | Amount |
|---|---|
| Solana account and rules, paid by the browser key | About 0.017 SOL, measured on 9 Nov 2026 with a new account |
| Swig wallet rent for the first partial repayment | About 0.003 SOL, shown with a **Fund** button |
