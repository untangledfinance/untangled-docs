# Fees and gas sponsorship

Leverage Yield moves value across three chains, so each step has a fee. This page lists who pays each one.

## Who pays

The fee sponsor is a service that pays the gas for some of the browser keys' transactions. It can be on or off. When it is on, the step is sponsored. When it is off, or it refuses a transaction, the browser key or the keeper key pays for that step. The page says so in one line.

| Cost | Paid by |
|---|---|
| Base transactions from your wallet: setup, Open, custody approvals, Deliver, and Repay and withdraw from your wallet | Your wallet, in ETH. Not sponsored. |
| Signer B's signed messages on Base | The fee sponsor, which broadcasts each message and pays the gas. Signer B holds no ETH. |
| Solana Open: the mint and the deposit to Kamino | The fee sponsor when it is on. Otherwise the browser key, in SOL. |
| Solana Close: the redeem from Kamino and the burn to Base | The fee sponsor when it is on and the browser key's rule is in place. Otherwise the browser key, in SOL. |
| Solana setup: the account, the token accounts and the rules | The browser key, in SOL. Not sponsored. |
| Solana Withdraw and send to Base, with your wallet signing the Solana side: the Circle message | Your Swig wallet, in SOL: about 0.0028 SOL for each run. Not sponsored at launch. See below. |
| Stellar keeper transactions: deposit, withdraw, approve and burn | The fee sponsor when it is on. Otherwise the keeper key, in XLM. |
| Stellar account deploy | The keeper key, in XLM. Not sponsored. |
| Circle's fee on Kamino | Taken from the USDC sent. See below. |

The sponsor checks each transaction before it adds its part of the fee. A transaction that fails the check is not sponsored. The limits on how much the sponsor pays are set by the service and are not listed here.

Signer B holds no ETH. The fee sponsor sends the messages that signer B signs on Base and pays their gas, so you do not fund signer B.

## The Circle message on Solana

When a Kamino run sends USDC to Base with **Withdraw and send to Base**, Solana creates a message account for the Circle transfer. The Swig wallet pays its rent, about 0.0028 SOL for each run. Your wallet signs that step, and at launch it is not sponsored. Keep enough SOL in the Swig wallet for each run. The **Fund** button on the Repay & withdraw tab sends SOL to the Swig wallet from the browser key.

## Circle's fee

Circle charges for the USDC that crosses from Base to the yield source. The fee depends on the transfer speed.

| Line | Speed | Fee |
|---|---|---|
| Kamino | Fast, when Circle's fee fits the limit | Up to 0.002 USDC |
| Kamino | Standard, when Fast's fee is above the limit | None. The transfer takes longer. |
| OctoLend | Standard | None |

When you press the button, the app asks Circle for the fee on that amount. It uses Fast when the fee fits the 0.002 USDC limit, and Standard otherwise. The review shows the fee before you sign. On a Close, when neither speed fits, the Close is refused with **Fee above limit**.

## The sponsor's messages

When the sponsor does not pay, the page shows one line under the step that was sent. The browser key or the keeper key pays instead.

| Message | What it means |
|---|---|
| Sponsor is off. This key pays. | The sponsor is not running for this app. |
| Sponsor limit reached. This key pays. | The sponsor has no more to pay for this key at the moment. |
| Sponsor refused. This key pays. | The sponsor did not sign the transaction after its checks. |
| Sponsor could not check it. This key pays. | The sponsor could not read the transaction it was given. |
| Sponsor unreachable. This key pays. | The page could not reach the sponsor. |

After a refusal, the page leaves the sponsor off for a while, and the key pays for those steps.

**This key pays** means the browser key or the keeper key covers the fee from its own balance. If the key is short, the page shows **Key SOL low** with the key's address and a copy button. Send SOL to that address, then try the step again.

## One-time costs

| Cost | Paid by |
|---|---|
| Solana account and rules | The browser key. The setup dialog shows the amount under the **Fees** step. |
| Swig wallet for the first partial repayment | The Swig wallet's SOL, topped up with the **Fund** button on the Repay & withdraw tab. The button sends SOL from the browser key. |
